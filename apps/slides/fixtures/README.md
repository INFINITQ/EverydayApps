# Public sample decks

Test files from the Apache POI project's test data
(<https://github.com/apache/poi/tree/trunk/test-data/slideshow>), Apache License 2.0.
They were made with PowerPoint, so they exercise what generated decks can't (real zip
layouts, SmartArt, charts with embedded workbooks, an old binary .ppt).

| File | What it covers |
|---|---|
| `SampleShow.pptx` | A small deck with notes |
| `SampleShow.ppt` | The same deck in the old binary format (.ppt read-only) |
| `smartart-simple.pptx` | SmartArt (data, layout, colors, drawing parts) |
| `pie-chart.pptx` | A chart with its embedded Excel workbook |

Never add personal or real-world documents here.
