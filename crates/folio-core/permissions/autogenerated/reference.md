## Default Permission

Everything a Folio app window needs from the shared core. Debug-only commands are not included.

#### This default permission set includes the following:

- `allow-app-ready`
- `allow-system-info`
- `allow-pick-open`
- `allow-pick-save`
- `allow-read`
- `allow-save`
- `allow-release`
- `allow-pick-folder`
- `allow-save-into-folder`
- `allow-release-folder`
- `allow-open-link`
- `allow-default-apps`
- `allow-open-default-apps`
- `allow-set-fullscreen`
- `allow-presenter-screen`
- `allow-take-pending`
- `allow-backups-usage`
- `allow-backups-clear`
- `allow-settings-get`
- `allow-settings-set`
- `allow-recent-list`
- `allow-recent-open`
- `allow-recent-remove`
- `allow-recent-clear`
- `allow-view-state-get`
- `allow-view-state-set`
- `allow-recovery-put`
- `allow-recovery-list`
- `allow-recovery-read`
- `allow-recovery-drop`
- `allow-recovery-origin`
- `allow-secure-put`
- `allow-secure-get`
- `allow-secure-delete`
- `allow-secure-keys`
- `allow-system`
- `allow-network-lock`
- `allow-caption-maximize-rect`
